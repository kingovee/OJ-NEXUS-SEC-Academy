# Support

- For reproducible bugs, use the repository's **Bug report** issue template.
- For learning content or product improvements, use **Feature request**.
- For setup questions, start with [README.md](README.md) and [docs/PROJECT-GUIDE.md](docs/PROJECT-GUIDE.md).
- Do not post passwords, personal data, confidential logs, or private system details in issues or discussions.

This is a community learning project, not a commercial support service or a source of emergency incident-response assistance.
