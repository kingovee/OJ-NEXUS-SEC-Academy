# Privacy — NEXUS//SEC Academy Beta

This release is a static educational site. It does not provide accounts, cloud synchronisation, tracking analytics or a student database.

- Learning progress, quiz results and optional case notes are saved in browser localStorage on the device.
- You can export progress from **My Progress** and delete saved learning progress using **Reset all local progress**.
- Changing browser/device or clearing site data can erase progress. Export first if you need a backup.
- Never enter real credentials, private logs or personal information in fictional exercises.
- When hosted on GitHub Pages, GitHub may process standard website requests under its own policies.
- CTF flags are stored client-side and are not suitable for competitive prizes or verified certificates.
