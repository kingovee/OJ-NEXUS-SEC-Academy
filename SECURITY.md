# Security Policy

## Scope

This policy covers security issues in the NEXUS//SEC Academy website and its source code. The terminal, attack library, CTFs, and live role range are browser-based educational simulations; they are not a production cyber range and do not execute operating-system commands or launch attacks.

## Reporting a vulnerability

Please do not publish an exploitable vulnerability or sensitive details in a public issue. Use GitHub's **Report a vulnerability** feature under the repository's Security tab when private vulnerability reporting is enabled. If that feature is unavailable, contact the repository maintainers through a private contact method listed in the repository profile.

Include a concise description, affected page or file, impact, and safe reproduction steps. Do not include real credentials, personal data, or third-party secrets.

## Safe-use note

Do not use the project to store sensitive information. Any external security testing must be limited to systems you own or have explicit written permission to assess.
