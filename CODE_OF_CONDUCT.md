# Code of Conduct

NEXUS//SEC Academy is a learning community. Everyone participating in project discussions, issues, reviews, and contributions is expected to help create a respectful and constructive environment.

## Expected behaviour

- Be respectful, patient, and welcoming to beginners.
- Give feedback about ideas and code, not personal characteristics.
- Explain disagreements calmly and assume good faith.
- Keep examples and discussions lawful, authorised, and focused on learning and defence.
- Respect privacy. Do not publish credentials, personal data, private logs, or information about systems you do not own or have permission to assess.

## Unacceptable behaviour

Harassment, discrimination, intimidation, personal attacks, doxxing, threats, and encouraging unauthorised activity are not acceptable.

## Reporting

Report conduct concerns privately to the repository maintainers using a private contact method configured on the repository. Do not post sensitive personal information in a public issue.

Maintainers may edit or remove content that violates this code and may restrict participation when necessary to protect the community.
